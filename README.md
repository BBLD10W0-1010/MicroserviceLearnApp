# **This repo is for [learning course about Microservice](https://www.youtube.com/watch?v=DgVjEo3OGBI&pp=ygUcYyMgbWljcm9zZXJ2aWNlcyBmdWxsIGNvdXJzZQ%3D%3D) Architecture from [Les Jackson](https://www.youtube.com/@binarythistle).** 
**_Dat`s a great video! Learned quite a lot from it, soooo thx to him!_**

It goes through:
* Building two .NET Microservices using the REST API pattern
* Working with dedicated persistence layers for both services
* Deploying our services to Kubernetes cluster
* Employing the API Gateway pattern to route to our services
* Building Synchronous messaging between services (HTTP & gRPC)
* Building Asynchronous messaging between services using an Event Bus (RabbitMQ)
